HOW TO USE THE QUARTER-CAR ROAD PROFILE TEST PACKAGE
====================================================

REQUIRED SOFTWARE
-----------------
- MATLAB
- Simulink
- Simscape
- Simscape Multibody

1. EXTRACT THE ZIP FILE
-----------------------
Right-click the ZIP file and extract it to a normal folder before opening
or running any MATLAB files.

2. CHECK THE FOLDER
-------------------
Keep all of these files together in the same folder:

- quarter_car_tire.slx
- runAllRoadProfiles.m
- roadInputForTire.m
- speedbump.m
- pothole.m
- roughroad.m
- ramp.m
- curvedramp.m

Do not run the project directly from inside the ZIP file.

3. OPEN THE PROJECT FOLDER IN MATLAB
------------------------------------
Open MATLAB.

In MATLAB's Current Folder panel, browse to the extracted project folder.

You can confirm MATLAB sees the main script by entering:

    which runAllRoadProfiles -all

4. CHECK THE SIMULINK MODEL
---------------------------
Open the model by double-clicking:

    quarter_car_tire.slx

The From Workspace block inside the model must use this variable name:

    roadInput

5. RUN ALL ROAD PROFILES
------------------------
In the MATLAB Command Window, enter:

    runAllRoadProfiles

The script will:

- generate the speed-bump profile
- generate the pothole profile
- generate the rough-road profile
- generate the straight-ramp profile
- generate the curved-ramp profile
- convert road distance into simulation time
- create the roadInput timeseries for Simulink
- run quarter_car_tire.slx once for each road
- display the five road-input graphs
- display a PASS or ERROR summary table
- save the test results in the road_test_results folder

6. VIEW THE FOUR VEHICLE-RESPONSE GRAPHS
----------------------------------------
Open the four Scope blocks in quarter_car_tire.slx.

The four Scope graphs show:

- tire position/deflection
- tire velocity
- suspension position/travel
- suspension velocity

Because all road profiles run one after another, the Scope windows normally
show the response from the final test after the script finishes.

7. TEST ONE ROAD PROFILE BY ITSELF
----------------------------------
After runAllRoadProfiles has finished, choose one road by entering one of
the following commands:

Speed bump:
    roadInput = roadInputs.speedbump;

Pothole:
    roadInput = roadInputs.pothole;

Rough road:
    roadInput = roadInputs.roughroad;

Straight ramp:
    roadInput = roadInputs.ramp;

Curved ramp:
    roadInput = roadInputs.curvedramp;

Then run the selected road with:

    set_param("quarter_car_tire", ...
        "StopTime", num2str(roadInput.Time(end)));

    sim("quarter_car_tire");

The same four Scope graphs will update for the selected road.

8. CHANGE THE VEHICLE SPEED
---------------------------
Open runAllRoadProfiles.m and change:

    vehicleSpeed = 15;

The value is in meters per second.

9. CHANGE THE SUSPENSION OR TIRE PARAMETERS
-------------------------------------------
The main parameters are near the top of runAllRoadProfiles.m:

    Kt = 250000;   % tire stiffness, N/m
    Ct = 200;      % tire damping, N*s/m
    Ks = 30000;    % suspension stiffness, N/m
    Cs = 3000;     % suspension damping, N*s/m
    mu = 65;       % unsprung mass, kg
    ms = 600;      % sprung mass, kg

These are preliminary engineering estimates and may be changed as the team
refines the model.

10. COMMON ERROR
----------------
Error:
    The Simulink model was not found

Fix:
Make sure quarter_car_tire.slx is in the exact same extracted folder as
runAllRoadProfiles.m and that its filename has not been changed.
